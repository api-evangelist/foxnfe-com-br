Central Fox Tecnologia LTDA provides a unified fiscal integration platform in Brazil, offering REST APIs, SDKs, and MCP to connect documents, systems, and tax returns. The service supports NF-e, NFC-e, and NFS-e operations, with AI assistance and compliance tools for businesses.

**Areas:** Finance · Tax · Integration · API · Brazil

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Central Fox Tecnologia LTDA: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
